# research

Research papers, one folder each. Every folder is a self-contained reproduction package: the paper,
its data, and the scripts that regenerate every number in it.

| paper | folder |
|---|---|
| *What Does a Sim-to-Real Correlation Support? Five One-Line Checks and a Twenty-Two-Paper Audit* | [`sim2real-correlation-audit/`](sim2real-correlation-audit/) |

Code is MIT-licensed (see `LICENSE`). Extracted datasets are released CC BY 4.0 — they are factual
coordinates recovered from the cited papers' own published figures; the figures themselves remain
their authors'. Citation info: `sim2real-correlation-audit/CITATION.cff`.
