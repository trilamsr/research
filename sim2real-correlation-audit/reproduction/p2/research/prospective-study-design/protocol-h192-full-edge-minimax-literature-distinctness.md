## Question

Are H186's full-edge compatible-box minimax theorem, H188's
arbitrary-reference extension, or their use in P2 materially occupied by
prior work?

This is a bounded collision search, not a systematic review and not proof of
novelty by absence.

## Frozen candidate units

Code each retained source against:

1. static observational equivalence from candidate-dependent context;
2. independently varying compatible target pair edges;
3. Borda value under a fixed opponent-reference distribution;
4. worst-compatible ex-ante expected regret of a policy lottery;
5. exact deterministic and randomized values for the uniform-reference box;
6. uniqueness of the uniform minimax lottery;
7. arbitrary positive reference weights;
8. exact weighted value \((2-r_{(1)}-r_{(2)})/8\);
9. complete optimizer face and its nonuniqueness boundary; and
10. robotics action-order or public-evaluation application.

A vocabulary match is not a theorem match. Online cumulative regret, a
parametric pairwise model, possible-winner enumeration, or robust ranking
without the same decision object must be coded separately.

## Coding and decisions

For each retained source record its stable identity, venue/version, retrieval
date, exact section/theorem locator, unit coding (`yes`, `partial`, `no`,
`unresolved`), object and assumptions, collision consequence, and uncertainty.
Check the primary full text before coding a theorem collision.

Classify:

- `occupied`: a source states the H186/H188 theorem object and material exact
  result;
- `material_narrowing`: a source owns a substantial theorem component or a
  more general result that directly specializes to it;
- `bounded_distinct_delta`: the closest sources occupy adjacent objects but
  the exact theorem delta survives this search; or
- `inconclusive`: access or semantic ambiguity blocks adjudication.

Regardless of classification, do not use “first,” “novel,” “new,” or
field-wide absence language. Expert human literature review remains required
before public novelty claims.

## Sealing and independence

The search may inspect theory and public protocol descriptions but not PhAIL
performance outcomes. Preserve collisions, nulls, and unfavorable scope
changes. Any later search is a separately versioned extension.
