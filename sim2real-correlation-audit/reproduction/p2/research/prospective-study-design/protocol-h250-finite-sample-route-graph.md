# Protocol: H250 finite-sample route-graph identification

Date fixed: 2026-08-10

Status: exploratory methods extension fixed before its synthetic known-answer
results were generated. No PhAIL, RoboArena, ArmnetBench, RRC, or other
performance outcome is opened or analyzed.

## Question and intended use

Can P2's exact route-graph analysis accept simultaneous uncertainty intervals
on observed comparison edges and return finite-sample-valid target-difference
bounds, possible and certified winners, and a minimax-regret lottery?

The intended user is a benchmark designer with a declared target, context
weights, policy roster, and valid edge-level uncertainty intervals. The
smallest useful result is a fail-closed linear program that reproduces P2's
point-identified known answers and propagates any jointly valid input intervals
without strengthening their assumptions.

## Model and estimand

For context (c), let (x^c\in[0,1]^K) be shared binary-success means and let
(E_c) be the oriented incidence matrix of the observed policy pairs. The
population edge differences obey

\[
\ell_c\le E_cx^c\le u_c.
\]

For fixed positive target weights \(\alpha_c\) summing to one, the target mean
is \(\mu=\sum_c\alpha_cx^c\). The program will compute:

1. the sharp lower and upper bounds on every \(\mu_i-\mu_j\);
2. policies that are best in at least one compatible completion;
3. a certified unique winner only when its lower difference against every
   competitor is strictly positive; and
4. the ex-ante minimax-regret lottery under the same compatible set.

The half-credit Borda regret is one half of success-mean regret, as in H233.

## Coverage statement

If the input edge intervals jointly contain the population differences with
probability at least \(1-\alpha\), then the projected target set contains the
population target with at least the same probability. All derived pairwise
bounds and any certified winner inherit that coverage. The projection does not
repair invalid edge intervals, dependence, adaptive sampling, target drift, or
missing context support.

As one optional construction, for \(M\) observed edges with independent
bounded half-credit outcomes \(Z\in[0,1]\), use the Bonferroni-Hoeffding radius

\[
\epsilon_e=\sqrt{\frac{\log(2M/\alpha)}{2n_e}},
\]

clip \(\hat q_e\pm\epsilon_e\) to \([0,1]\), and map the interval to the
shared-success difference through \(d_e=2q_e-1\). Across-edge independence is
not required for the Bonferroni step, but each edge interval must be valid for
its own sampling unit. Clustered or adaptive trials require a separately valid
edge-interval procedure.

## Fixed known answers and gates

1. Point intervals for H233's three-policy route pattern must reproduce the
   unique lottery \((2/3,0,1/3)\) and regret \(1/12\) to \(10^{-9}\).
2. A connected exact path generated by \(x=(0.8,0.5,0.2)\) must certify policy
   1 as the unique winner and recover every target difference.
3. A disconnected exact graph with one observed edge must retain multiple
   possible winners and certify none.
4. Empty, malformed, out-of-range, or infeasible interval systems must fail
   closed.
5. Point-interval results must agree with direct vertex enumeration on the
   H233 case; interval widening must not narrow any projected bound.
6. The implementation and retained result must bind the protocol and input
   known answers by SHA-256 and reproduce deterministically.

## Interpretation and stop conditions

This is a generic confidence-set projection and robust optimization layer, not
a new confidence-interval theory or a claim of novelty. It supports a paper
contribution only as an executable bridge from P2's identification geometry to
finite-sample inputs.

Stop promotion if the point-known answers fail, if widening an input interval
narrows a reported target interval, if infeasible systems do not fail closed,
or if the claimed coverage exceeds the validity of the supplied edge
intervals. Do not apply the method to PhAIL outcomes: H187 and H218--H221 leave
that outcome phase unauthorized.
